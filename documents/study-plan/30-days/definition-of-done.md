# Definition of Done (FE)

Một feature **chưa Done** chỉ vì “UI chạy + API chạy”.

Checklist trước khi coi là xong:

```text
[ ] User flow đúng
[ ] Acceptance criteria pass
[ ] UI consistent
[ ] Loading / empty / error handled
[ ] Responsive strategy verified
[ ] Accessibility checked
[ ] API contract validated
[ ] Security reviewed
[ ] Performance reasonable
[ ] Automated tests added
[ ] Manual regression done
[ ] AI-generated code reviewed
[ ] Code review complete
[ ] Documentation / evidence updated
[ ] Known limitations documented
```
