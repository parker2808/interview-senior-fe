# senior-fe-lab

Companion repo for the 30-day Senior FE plan.

- Plan / theory / worksheets / **algo đề bài**: `interview-senior-fe` (hub)
- **Code + tests bạn push mỗi ngày**: repo này

## Quick start

```bash
npm install
npm run dev:react
npm run algo:test
```

## Daily

1. Open plan Day N → tab **Lab setup**
2. Work in `apps/react`, `apps/next`, or `algo/day-NN`
3. `git commit -m "day-NN: ..."` && `git push`

## Algo

```bash
# run all
npm run algo:test

# run one day (example day 1)
npm run algo:test:day -- 1
```

Đề bài đọc từ plan hub: `artifacts/algo/problems/day-NN.md`.
