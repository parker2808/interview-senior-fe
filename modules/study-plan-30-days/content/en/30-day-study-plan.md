# 30-day study plan — clean overview

**Timeline:** Day 1 = **03/10/2026** → Day 30 = **01/11/2026**  
**Daily pace:** about **90–120 minutes**  
**Source of truth:** use the **Plan homepage** to open each day, then switch between the Plan and Lab tabs.

---

## How to use this plan

Each day in the app now follows one structure:

1. **Short goal** — what today is trying to improve
2. **Read / review** — links into the existing FE docs
3. **Practice Q&A** — interview questions linked to the real bank
4. **Small hands-on task** — enough to talk about in an interview
5. **One algorithm task** — light but steady practice
6. **Done checklist** — a clear stopping point

If time is tight, keep the order:
**docs → Q&A → one small hands-on task → one algorithm problem**.

## 4 weeks + the final days

### Week 1 — Design system + UI clarity

**Goal:** review reusable primitives, states, responsive trade-offs, and accessibility basics.

- Day 01 — Inventory the UI system
- Day 02 — Make UI states readable
- Day 03 — Accessible forms and feedback
- Day 04 — Responsive data-heavy UI
- Day 05 — Keyboard-first interaction review
- Day 06 — Component APIs with TypeScript
- Day 07 — Week 1 mini redesign

### Week 2 — JS/TS + Vue/Nuxt refresh

**Goal:** tighten the fundamentals Parker already uses in production so the interview answers sound sharper.

- Day 08 — JavaScript execution model
- Day 09 — Promises, fetch, and browser events
- Day 10 — TypeScript for real frontend models
- Day 11 — Vue reactivity and composables
- Day 12 — Nuxt rendering and data fetching
- Day 13 — State ownership, Pinia, and cache boundaries
- Day 14 — Performance and debugging review

### Week 3 — React + Next.js from a Vue lens

**Goal:** learn React and Next.js by transferring principles from Vue/Nuxt instead of bluffing production depth.

- Day 15 — React mental model for a Vue dev
- Day 16 — State, refs, and controlled inputs in React
- Day 17 — Effects, async cleanup, and error boundaries
- Day 18 — App Router, layouts, loading, and errors
- Day 19 — Next data fetching, cache, and rendering modes
- Day 20 — Server Actions, middleware, SEO, and assets
- Day 21 — Small Next.js hands-on task

### Week 4 — System design + behavioral integration

**Goal:** connect frontend depth with architecture, delivery, and interview storytelling.

- Day 22 — Design an admin dashboard
- Day 23 — Data-heavy surfaces and performance trade-offs
- Day 24 — Security, release, and resilience
- Day 25 — Behavioral stories: intro, impact, seniority
- Day 26 — Behavioral stories: project, trade-offs, and the React gap
- Day 27 — Cross-stack review and weak spots
- Day 28 — Mock round #1

### Final days — Review + mock interview

- Day 29 — Final review and company fit
- Day 30 — Full mock interview + retrospective
