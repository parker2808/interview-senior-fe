# Project context — Senior FE 30-day interview prep

This is **senior interview practice**, not a Day-1 Capstone build.

## Goals

- Answer frontend questions the way a person who has shipped production does: decision → constraint → failure mode → measure
- Vue 3 + TypeScript is the home stack; React / Next is a comparison lane, not a bluff
- One small algorithm each day to keep live-coding sharp
- Code lives in the **companion lab repo**; this hub holds the plan, docs, Q&A, and prompts

## Daily shape (90–120 minutes)

1. **Short goal** on the Plan tab — what decision you are practicing today
2. **Docs** — open the knowledge base in a **new tab**, read the relevant section only
3. **Q&A** — open the bank in a **new tab**, answer out loud, then compare
4. **Lab / hands-on** — one artifact you can retell in an interview
5. **One algorithm** — prompt in the plan, code in the lab repo
6. **Checklist** — stop when it is enough

If time is tight: **docs + Q&A + one hands-on + one algorithm**.

## What not to do

- Do not turn each day into an npm-install tutorial
- Do not pretend React/Next is your main production stack
- Do not try to finish all of `documents/` in one sitting
- Do not navigate away from the day page to read docs or Q&A — they open in a new tab
