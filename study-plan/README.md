# Study plan (30 days)

Materials and a small follow/check UI for the Senior FE interview prep calendar (03/10 → 01/11/2026).

## Layout

```
study-plan/
  30-days/          # markdown plan, starters, worksheets, capstone stubs
  app/              # Vite + Vue 3 progress UI
```

## Live UI

[https://parker2808.github.io/interview-senior-fe/](https://parker2808.github.io/interview-senior-fe/)

Deploy: GitHub Actions → Pages (`.github/workflows/deploy-study-plan.yml`).

## Quick start (UI)

```bash
cd study-plan/app
npm install
npm run dev
```
